##Comment un simple programme peut-il montrer qu'un petit ralentissement peut provoquer un gros embouteillage, même sans accident ni obstacle ?
Chaque voiture :
- avance à une certaine vitesse ;
- garde une distance avec la voiture devant elle ;
- ralentit si elle se rapproche trop ;
- accélère lorsque la route se libère.
